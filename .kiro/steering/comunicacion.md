# Comunicación con Claude Code

En este proyecto también trabaja Claude Code. Se comunican por la carpeta `comunicacion/`:

- Al empezar cada tarea, lee `comunicacion/para-kiro.md` y atiende los mensajes con `Estado: PENDIENTE`.
- Para escribirle a Claude, agrega un mensaje al final de `comunicacion/para-claude.md`.
- Sigue el formato y las reglas de `comunicacion/README.md`.
